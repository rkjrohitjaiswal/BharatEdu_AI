## Executive Summary

The **Parent/Guardian Learning Insights & Progress Report** provides a privacy-first, secure progress portal for parents and guardians to track their child's educational progress in BharatEdu AI without compromising private student data.

Key System Highlights:
- **User Role System Extension:** Safely adds `'parent'` to allowed user roles without modifying `'student'` and `'teacher'` functionality.
- **Secure Invitation Linking Service (`parent-link.service.ts`):** Prevents unauthorized student data access by requiring a short-lived (15 min), single-use invitation code generated by the student (`POST /api/student/parent-link/invite`) and accepted by the parent (`POST /api/parent/link-student`). Raw student IDs cannot be submitted to bypass authorization.
- **Privacy-First Data Model:** Parents receive aggregated educational progress (overall mastery, subject breakdown, progress trend, practice streak, high-level learning gaps, study-plan task progress, scholarship count). Private tutor chat logs, raw teacher comments, question answer keys, and secrets are strictly excluded.
- **Read-Only Non-Mutation:** Parents have zero permission or endpoints to modify student mastery, practice answers, learning gaps, scores, or teacher data.
- **Deterministic Progress Trend Engine (`rules.ts`):** Calculates trend (`improving`, `stable`, `needs_attention`) with a bounded score (0–100). The LLM is strictly prohibited from altering scores or risk classifications.
- **AI Summary & Offline Fallback (`ai-enricher.ts`):** Uses OpenAI (`gpt-4o-mini`) strictly to generate brief, encouraging parent summaries in the parent's preferred language (English, Hindi, Gujarati). If `AI_API_KEY` is missing or fails, deterministic templates are used with `aiEnhanced: false`.
- **Interactive UI Workflows:** Creates `ParentDashboardPage.tsx` (`/parent/dashboard`), `ParentStudentOverviewPage.tsx` (`/parent/overview/:studentId`), `ParentLinkPage.tsx` (`/parent-link`), student selector, and custom parent sidebar navigation.

## Section 1: Architecture & Data Flow

```
Student generates 15-min Invitation Code (POST /api/student/parent-link/invite)
 ↓
Parent accepts Invitation Code (POST /api/parent/link-student)
 ↓
Parent-Student Link Activated (ParentStudentLink model status: 'active')
 ↓
Parent queries Linked Students List (GET /api/parent/students)
 ↓
Parent requests Student Overview (GET /api/parent/students/:studentId/overview)
 ↓
Deterministic Progress Trend Engine (rules.ts calculates trend & score 0-100)
 ↓
AI Parent Summary Enricher (ai-enricher.ts generates parent advice or fallback)
 ↓
Parent Dashboard UI & Progress Portal (/parent/dashboard & /parent/overview/:studentId)
```

## Section 2: REST API Endpoints

### 1. List Linked Active Students
- **Endpoint:** `GET /api/parent/students`
- **Headers:** `Authorization: Bearer <parent_jwt>`
- **Response Payload (`200 OK`):**
  ```json
  {
    "success": true,
    "data": [
      {
        "linkId": "link_1787165935_8x9a",
        "relationship": "mother",
        "linkedAt": "2026-08-20T00:26:44.000Z",
        "student": {
          "_id": "66c3a10e82f1b4a09c211e4f",
          "name": "Rohit Jaiswal",
          "email": "rohit@example.com",
          "preferredLanguage": "english"
        }
      }
    ]
  }
  ```

### 2. Fetch Linked Student Overview
- **Endpoint:** `GET /api/parent/students/:studentId/overview`
- **Headers:** `Authorization: Bearer <parent_jwt>`
- **Response Payload (`200 OK`):**
  ```json
  {
    "success": true,
    "data": {
      "student": { "id": "66c3a10e82f1b4a09c211e4f", "name": "Rohit Jaiswal", "classLevel": 8, "preferredLanguage": "english" },
      "overallMastery": 50,
      "progressTrend": { "trend": "stable", "score": 56, "explanation": "Your child is maintaining steady learning consistency." },
      "practiceStreak": 1,
      "totalPracticeTimeMinutes": 0,
      "subjectPerformance": [
        { "subjectId": "math", "subjectName": "Mathematics", "masteryScore": 58, "totalTopics": 10, "masteredTopics": 6 },
        { "subjectId": "science", "subjectName": "Science", "masteryScore": 74, "totalTopics": 12, "masteredTopics": 9 }
      ],
      "activeGapsSummary": [],
      "studyPlanProgress": { "totalTasks": 4, "completedTasks": 2, "pendingTasks": 2 },
      "scholarshipOpportunitiesCount": 3,
      "aiLearningSummary": {
        "summary": "Rohit Jaiswal is maintaining an overall learning mastery of 50%.",
        "encouragement": "Consistent daily 15-30 minute study sessions build solid long-term learning foundations.",
        "suggestions": ["Encourage regular 15-minute daily practice sessions."],
        "aiEnhanced": false
      }
    }
  }
  ```

### 3. Invitation & Link Management
- `POST /api/student/parent-link/invite`: Student generates 15-min invitation code (`{ "relationship": "mother" }`).
- `GET /api/student/parent-link/invitations`: Student views active invitations.
- `DELETE /api/student/parent-link/invitations/:code`: Student revokes an invitation code.
- `POST /api/parent/link-student`: Parent accepts invitation code (`{ "code": "LINK-DWNC3J" }`).

## Section 3: Security & Access Control Matrix

| Security Test Case | Request Context | Result | Status |
| :--- | :--- | :---: | :---: |
| **Parent A -> Own linked student overview** | `GET /api/parent/students/:studentId/overview` | 🟢 200 OK | **ALLOWED** |
| **Parent B -> Parent A linked student** | `GET /api/parent/students/:studentId/overview` (Parent B JWT) | 🔴 403 Forbidden | **BLOCKED** |
| **Student -> Parent API endpoints** | `GET /api/parent/students` (Student JWT) | 🔴 403 Forbidden | **BLOCKED** |
| **Teacher -> Parent API endpoints** | `GET /api/parent/students` (Teacher JWT) | 🔴 403 Forbidden | **BLOCKED** |
| **Unauthenticated access** | Any protected endpoint without JWT | 🔴 401 Unauthorized | **BLOCKED** |
| **Single-Use Code Enforcement** | Re-submitting accepted invitation code | 🔴 400 Bad Request | **BLOCKED** |
| **Revoked Code Enforcement** | Submitting revoked invitation code | 🔴 400 Bad Request | **BLOCKED** |
| **Read-Only Non-Mutation** | Parent overview requests | 🟢 Mastery Unchanged | **VERIFIED** |
